# Product screenshots

This directory is reserved for the screenshots displayed in the main project README.

Add the following files when the interface is ready to publish:

| Filename | Suggested content |
| --- | --- |
| `dashboard-overview.png` | Main dashboard with KPIs, incident trend, health, and recent incidents |
| `live-infrastructure.png` | EC2, DynamoDB, and RDS metric charts with lifecycle markers |
| `incident-detail.png` | Incident evidence, diagnosis, business impact, remediation, and verification |

For consistent GitHub rendering, use PNG or WebP images around 1440 px wide, hide credentials and account identifiers, and capture the screens with representative demo data.
